# DefendTaipei-Lab 保衛台北

以真實台北街道為戰場的生存遊戲原型：玩法參考《Project Zomboid》（俯視生存沙盒），但敵人是已經佔領台北的解放軍佔領部隊。你是萬華巷弄裡的倖存者，搜刮物資、避開巡邏、一區一區奪回街區。

**線上遊玩：** https://lijiabao1998.github.io/DefendTaipei-Lab/

## 操作
| 按鍵 | 功能 |
|---|---|
| WASD | 移動 |
| Shift | 奔跑（噪音大、耗體力） |
| C | 切換潛行（慢、無腳步聲、較難被看見） |
| 滑鼠 / 左鍵 | 瞄準 / 攻擊（近戰從背後偷襲傷害×3） |
| E | 搜刮附近容器／上下車／和 NPC 交談 |
| Tab / I | 背包（點物品使用或裝備） |
| B | 用鐵鎚+木板封門／拆除 |
| Z | 室內睡覺（時間快轉） |
| F | 手電筒 |
| 空白鍵 | 翻越矮牆 |
| Q | 推開敵人 |
| 1 / 2 / 3 | 時間 ×1 / ×3 / ×20 |
| M | 生存者地圖（Esc 關閉） |
| 滾輪 | 縮放 |

手機：畫面下方的虛擬搖桿移動（推到底奔跑），上車後同一個搖桿駕駛；地圖按右側 🗺。

## v0.1 內容
- 萬華／西門町約 1 km² 真實街道與 497 棟建築（OpenStreetMap），可進入建築、屋頂與前景牆面自動透明化
- 騎樓柱廊、鐵窗、頂樓加蓋鐵皮屋、水塔、機車、諧仿招牌（7-12、康是福藥局…）
- 飽足／水分／疲勞／生命、流血與止血、死亡即永久結束（刪除存檔）
- 解放軍巡邏：視野錐（白天遠、夜間近）、聽覺（槍聲約 40–55m）、搜索與交火；夜間宵禁有額外巡邏隊
- 9 個街區，消滅區內全部佔領軍即奪回該街區
- 日夜循環（1 秒 = 遊戲 1 分鐘）、localStorage 自動存檔

## 開發
```
npm install
npm run dev                      # 開發伺服器
npm run typecheck                # TypeScript 型別檢查
npm run format                   # Prettier 排版（設定在 .prettierrc.json）
npm run build && npm run smoke   # 建置後跑冒煙測試（Playwright：選角、序章、移動、背包、搜刮、夜間）
npm run fetch-osm                # 重新從 Overpass API 抓取地圖
node scripts/tiles.mjs           # 重新切 200 m 道路細節圖塊（public/data/tiles/）
```
- 推到 `main` 會由 GitHub Actions 建置並部署到 GitHub Pages。
- `scripts/checks/` 是各版本的功能截圖腳本（例如 `node scripts/checks/v18veh.mjs`），需要先 `npm run preview`；截圖存到 `shots/`。共用設定見 `scripts/lib.mjs`：`URL`（遊戲網址）、`SHOTS_DIR`（截圖資料夾）、`PW_CHROMIUM`（沒有安裝 Playwright 瀏覽器時指定 Chromium 路徑）。
- 多人連線伺服器在 `server/`，說明見 `server/README.md`。

## v7 — 時間系統
- 新遊戲可選一天長度 1／2／4 小時（存檔保存）；劇情依遊戲內時鐘。
- 快轉 1x／3x／20x（HUD 按鈕或 1/2/3 鍵），睡覺自動快轉；敵人接近、噪音、受傷時自動降回 1x。
- 宵禁 20:00–06:00：視野縮小、巡邏增加、手電筒光錐。飢餓／口渴／疲勞／腐敗依遊戲時間計算。
- 地下電台廣播、空投事件（紅色煙霧，解放軍會爭奪）、下雨（地面變濕、雨聲）、雨水桶集水（停水後仍可用）。
- 鐵皮／雨遮改為灰綠、青與褪色鐵鏽紅；攤車移至人行道與騎樓；騎樓柱只出現在立面前；空地改為鄰里公園或停車場。
- 路面：裂縫變細淡、油漬變淡、積水只在下雨時明顯、電線不投影、只保留主幹道連續中線、陰影 normalBias。

## v8 — 撤離結局（另一個結局，奪回之路保留）
- **直升機撤離**：第 6 天晚上電台預告；第 7 天 06:00 廣播開啟撤離窗口，至第 8 天 18:00 永久關閉。西側河濱撤離區（綠色 H、橘旗、紅色信號彈）；HUD 顯示剩餘時間。抵達即播放動畫：通用低多邊形直升機接應 → 飛越台灣海峽 → 降落福特號航空母艦（CVN-78）甲板 → 結算卡。
- **線人＋小艇**：每局線人隨機出現在廟口／柑仔店後巷／公園，給出宵禁時段的河岸接頭點。30% 是佔領軍陷阱：假線人說錯街名、要你「一個人來、武器留下」；廟口阿伯會提醒。可事先偵察（廂型車、無拖船痕跡 vs 藏好的橡皮艇）或用收音機／物資向「自由之聲」查證。中陷阱有 3 秒反應時間，可逃進巷子或跳進河；逃脫後該處標為危險區，叛徒躲回街區，抓到他會供出真接頭點或佔領軍前哨（計入奪回）。看穿陷阱可反伏擊並取得裝備箱。真線人：小艇沿淡水河出海，與福特號會合。
- 結算卡可選「繼續留在萬華（奪回之路）」或新遊戲。

## v12 — FPV 自殺無人機與解放軍偵察無人機
- 零件（無刷馬達×4、4S 鋰電池、類比圖傳、碳纖機架）散落民宅／警局；使用機架＋手榴彈組裝。成品 FPV 也會出現在空投與士兵（特戰更常見）遺留裝備中。一次性。
- 駕駛視角：類比圖傳雜訊／色偏／雪花、OSD（RSSI 訊號格、LQ、電壓／電量、高度、速度、油門、計時）。電池約 2.5 分鐘。
- 操控：桌機滑鼠俯仰／滾轉、W/S 油門、A/D 偏航、Esc 放棄（指標鎖定）；手機雙搖桿（左＝油門／偏航、右＝俯仰／滾轉）。有慣性、重力、陣風（下雨更強）。
- 訊號隨距離與建築遮擋衰減，解放軍檢查哨的干擾站附近壓制訊號，可能斷訊墜毀。
- 撞擊即引爆；從上方俯衝命中裝甲車頂可擊毀（主要反裝甲手段），側面撞擊傷害較低。
- 解放軍偵察無人機盤旋並有嗡嗡聲；在空曠處被盯上約 2.5 秒會招來砲擊與巡邏隊，躲進騎樓或室內可避免。

## v13 — 國軍、戰車支援與「奪回萬華」結局
- 國軍武器（5.56×45mm NATO，與解放軍 5.8×42mm 不通用）：T91、T65K2、T75 班用機槍、T93 狙擊槍（7.62×51mm）、T75 手槍（9mm）；反裝甲：紅隼（可裝填）、AT4（一次性）、標槍（稀有，頂部攻擊）。
- 觸發一：奪回第 2 個街區後，「自由之聲」通報國軍特戰在附近；據點出現國軍補給箱，空投開始帶國軍武器，附近有受傷聯絡官的背包（損壞無線電）。
- 觸發二：用鋰電池＋圖傳零件修好無線電，呼叫 CM-32 雲豹／CM-11 勇虎／M1A2T 沿最近的主要道路推進，摧毀佔領軍裝甲、據點與士兵；冷卻 4 分鐘，通話聲會引來巡邏。載具由 AI 控制，玩家不能駕駛。
- 觸發三：奪回 7/9 街區後全面反攻，國軍戰車縱隊開進西園路；奪回全部街區即進入新結局「奪回萬華」（運鏡過場＋結局卡），與兩種福特號撤離結局並存。

## v14 — 更精密的 FPV 飛行模型與類比圖傳
- 飛行：240 Hz 固定步長；四顆馬達各自推力（∝ 轉速²）與反扭力、馬達加減速延遲、Betaflight 風格 RC rate／super rate／expo、角速度 PI 控制＋air mode 混控、30° 鏡頭上仰（ACRO 模式，需要壓頭才會前進）。
- 機體座標二次方阻力、陣風、地面效應（低空推力增加）、下降穿過自己的槳洗會抖動失穩（PROPWASH）。
- 4S 鋰電：開路電壓隨電量下降、內阻壓降（大油門瞬間電壓下沉）、電流與 mAh 統計、低電壓斷電。
- 碰撞：高速（>4.5 m/s）撞擊引爆；低速擦撞會反彈翻滾，連撞 3 次或翻肚 2.5 秒結束飛行。
- 圖傳：5.8 GHz 路徑損耗＋建築遮擋＋干擾站→RSSI；雜訊隨 RSSI 增加，多重路徑鬼影、破碎橫條、同步遺失捲動、弱訊號黑白、掃描線與暈影；DVR 錄影標記；Betaflight 風格 OSD（電壓、電流、mAh、RSSI dBm、LQ、人工水平儀、速度、高度、回家箭頭與距離、警告）。
